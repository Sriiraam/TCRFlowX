# Security Policy

## Sensitive Information

TCRFlowX repositories must not contain:

- Cloud credentials
- API keys
- Access tokens
- Software license keys
- Passwords
- Patient-identifiable information

Secrets should be provided through environment variables, secret-management systems, or platform-specific credential mechanisms.

## Reporting Security Issues

Do not publicly disclose security vulnerabilities that could expose credentials, sensitive data, or computational infrastructure.

Security concerns should be reported privately to the repository maintainer.

## Research Data

Users are responsible for ensuring that genomic and clinical data processed with TCRFlowX comply with applicable consent, privacy, institutional, and data-governance requirements.
