# TCRFlowX Dataset

## Study Accessions

- GEO Series: GSE337136
- BioProject: PRJNA1484115
- SRA Study: SRP713941

## Disease

Classical Hodgkin lymphoma (cHL)

## Study Design

Longitudinal TCR-seq profiling of a patient with Hodgkin lymphoma during PD-1 inhibitor therapy.

Clinical sampling:

Timepoint 1:
- Pre-treatment PBMC
- Pre-treatment lymphoid tumor tissue

Timepoint 4:
- Relapse PBMC
- Patient off PD-1 inhibitor

Timepoint 6:
- Progressive-disease PBMC
- Progressive-disease lymphoid tumor tissue
- Patient on PD-1 inhibitor

## Sequencing Protocol

- Assay: Bulk TCR sequencing
- Target receptor chain: TCR beta (TRB)
- Starting molecule: Genomic DNA
- Library preparation: LymphoTrack TRB Assay Panel
- Manufacturer: Invivoscribe
- DNA extraction: Qiagen AllPrep DNA/RNA protocol
- Sequencing platform: Illumina MiSeq
- Library layout: Paired-end
- Organism: Homo sapiens

## Original Data Processing

The study authors processed raw TCR-seq FASTQ files using MiXCR to quantify TCR clonotypes.

Deposited processed files contain TCRβ clonotype frequencies and provide an independent reference for validation of TCRFlowX.

## Sample Types

- PBMC: 3 samples
- Lymphoid tumor tissue: 2 samples
- Total samples: 5
